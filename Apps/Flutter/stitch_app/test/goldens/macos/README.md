# macOS Flutter golden baselines

These 30 PNGs were captured from the macOS Flutter test run `38811272193` at source commit `39a2631b83beb3efc1d92cd5f9aec4a3ca715ca3`. They provide a separate exact pixel baseline for macOS font and stroke rasterization differences. The ordinary `test/goldens/` files remain the Windows baselines.

The screenshot tests use the default zero-tolerance golden comparator on both platforms. Capturing these test baselines does not claim GUI, hardware, or visual product acceptance.
